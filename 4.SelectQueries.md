# SELECT Queries

The `SELECT` statement is used to retrieve data from a table. The examples below use the `students` table:

```text
students(student_id, first_name, last_name, email, phone, marks, rank)
```

## Selecting All Columns

Use `*` to select every column:

```sql
SELECT *
FROM students;
```

## Selecting Specific Columns

Specify only the columns that are required:

```sql
SELECT student_id, first_name, last_name, marks
FROM students;
```

Selecting specific columns makes the result easier to read and avoids retrieving unnecessary data.

## Using `WHERE`

The `WHERE` clause filters rows according to a condition.

### Equal To

```sql
SELECT *
FROM students
WHERE student_id = 101;
```

### Not Equal To

SQL supports both `<>` and, in many databases, `!=`:

```sql
SELECT *
FROM students
WHERE marks <> 40;
```

### Greater Than and Less Than

```sql
SELECT first_name, marks
FROM students
WHERE marks > 80;
```

```sql
SELECT first_name, marks
FROM students
WHERE marks <= 50;
```

The commonly used comparison operators are:

| Operator | Meaning |
|---|---|
| `=` | Equal to |
| `<>` or `!=` | Not equal to |
| `>` | Greater than |
| `<` | Less than |
| `>=` | Greater than or equal to |
| `<=` | Less than or equal to |

## Conditional Operators

### `AND`

`AND` returns rows that satisfy all conditions:

```sql
SELECT *
FROM students
WHERE marks >= 80
  AND `rank` <= 10;
```

### `OR`

`OR` returns rows that satisfy at least one condition:

```sql
SELECT *
FROM students
WHERE marks >= 90
   OR `rank` = 1;
```

### `NOT`

`NOT` reverses a condition:

```sql
SELECT *
FROM students
WHERE NOT marks < 40;
```

### Combining Conditions

Use parentheses to make the intended logic clear:

```sql
SELECT *
FROM students
WHERE (marks >= 90 OR `rank` = 1)
  AND first_name <> 'Ravi';
```

## `BETWEEN`

`BETWEEN` selects values within an inclusive range. The boundary values are included:

```sql
SELECT *
FROM students
WHERE marks BETWEEN 60 AND 80;
```

The above is equivalent to:

```sql
SELECT *
FROM students
WHERE marks >= 60
  AND marks <= 80;
```

`BETWEEN` can also be used with dates:

```sql
SELECT *
FROM students
WHERE student_id BETWEEN 101 AND 110;
```

## `IN`

`IN` checks whether a value matches any value in a list:

```sql
SELECT *
FROM students
WHERE student_id IN (101, 103, 105);
```

This is shorter than using multiple `OR` conditions:

```sql
SELECT *
FROM students
WHERE student_id = 101
   OR student_id = 103
   OR student_id = 105;
```

Use `NOT IN` to exclude values:

```sql
SELECT *
FROM students
WHERE `rank` NOT IN (1, 2, 3);
```

## `LIKE`

`LIKE` is used for pattern matching in text columns.

Wildcards:

- `%` matches zero or more characters.
- `_` matches exactly one character.

### Names Starting With a Value

```sql
SELECT *
FROM students
WHERE first_name LIKE 'A%';
```

This returns names beginning with `A`, such as `Asha` and `Arjun`.

### Names Ending With a Value

```sql
SELECT *
FROM students
WHERE last_name LIKE '%an';
```

### Names Containing a Value

```sql
SELECT *
FROM students
WHERE first_name LIKE '%ri%';
```

### Matching a Fixed Number of Characters

```sql
SELECT *
FROM students
WHERE first_name LIKE 'A___';
```

This matches a four-character name beginning with `A`.

Use `NOT LIKE` to exclude a pattern:

```sql
SELECT *
FROM students
WHERE email NOT LIKE '%@example.com';
```

## Checking for `NULL`

`NULL` means that a value is missing or unknown. Use `IS NULL` or `IS NOT NULL`; do not use `= NULL`.

```sql
SELECT *
FROM students
WHERE phone IS NULL;
```

```sql
SELECT *
FROM students
WHERE phone IS NOT NULL;
```

## `ORDER BY`

Use `ORDER BY` to sort the result.

### Ascending Order

Ascending order is the default:

```sql
SELECT first_name, marks
FROM students
ORDER BY marks;
```

You can also write `ASC` explicitly:

```sql
SELECT first_name, marks
FROM students
ORDER BY marks ASC;
```

### Descending Order

```sql
SELECT first_name, marks
FROM students
ORDER BY marks DESC;
```

### Sorting by Multiple Columns

The database sorts by the next column when two rows have the same value in the previous column:

```sql
SELECT first_name, last_name, marks
FROM students
ORDER BY marks DESC, last_name ASC;
```

## `LIMIT`

`LIMIT` restricts the number of rows returned:

```sql
SELECT *
FROM students
LIMIT 5;
```

To find the five students with the highest marks, sort first and then limit the result:

```sql
SELECT first_name, marks
FROM students
ORDER BY marks DESC
LIMIT 5;
```

## `OFFSET`

`OFFSET` skips a specified number of rows. It is generally used with `LIMIT` for pagination:

```sql
SELECT *
FROM students
ORDER BY student_id
LIMIT 5 OFFSET 10;
```

This skips the first 10 rows and returns the next 5 rows.

In MySQL, the following alternative syntax is also supported:

```sql
SELECT *
FROM students
ORDER BY student_id
LIMIT 10, 5;
```

Here, `10` is the offset and `5` is the number of rows to return.

## Complete Query Examples

### Students with High Marks

```sql
SELECT student_id, first_name, marks
FROM students
WHERE marks >= 75
ORDER BY marks DESC;
```

### Students in a Marks Range with a Specific Rank

```sql
SELECT first_name, marks, `rank`
FROM students
WHERE marks BETWEEN 70 AND 90
  AND `rank` IN (5, 6, 7, 8, 9, 10)
ORDER BY marks DESC
LIMIT 10;
```

### Second Page of Results

If each page contains 10 rows, the second page starts after the first 10 rows:

```sql
SELECT student_id, first_name, last_name, marks
FROM students
ORDER BY student_id
LIMIT 10 OFFSET 10;
```

## General Query Order

When these clauses are used together, write them in this order:

```sql
SELECT column_names
FROM table_name
WHERE condition
ORDER BY column_name
LIMIT number OFFSET number;
```

For example:

```sql
SELECT first_name, marks
FROM students
WHERE marks >= 60
  AND first_name LIKE 'A%'
ORDER BY marks DESC
LIMIT 3 OFFSET 0;
```

## Interview Questions and MCQs

### 1. Which SQL statement is used to retrieve data?

A. `INSERT`
B. `SELECT`
C. `UPDATE`
D. `DELETE`

**Answer:** B

### 2. What is the purpose of the `WHERE` clause?

A. To sort rows
B. To filter rows according to a condition
C. To rename a table
D. To delete a database

**Answer:** B

### 3. Which operator means “not equal to”?

A. `<>`
B. `=>`
C. `==`
D. `><`

**Answer:** A

### 4. Which operator requires all conditions to be true?

A. `OR`
B. `NOT`
C. `AND`
D. `IN`

**Answer:** C

### 5. Which query returns students whose marks are between 60 and 80, including 60 and 80?

A. `WHERE marks > 60 AND marks < 80`
B. `WHERE marks BETWEEN 60 AND 80`
C. `WHERE marks IN 60 TO 80`
D. `WHERE marks RANGE 60, 80`

**Answer:** B

### 6. What does the following query do?

```sql

FROM students
WHERE student_id IN (101, 103, 105);
```

A. Returns students whose IDs are 101, 103, or 105
B. Returns students whose IDs are between 101 and 105
C. Returns only students with all three IDs
