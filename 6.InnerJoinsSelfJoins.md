# Inner Joins in SQL

A **join** combines rows from two or more tables using a related column.

Assume these tables:

```text
students(student_id, first_name, last_name, marks, rank, age, department_id)
departments(department_id, name, hod)
```

The `department_id` column connects a student to a department.

Example data:

### `students`

| student_id | first_name | last_name | marks | rank | age | department_id |
|---:|---|---|---:|---:|---:|---:|
| 101 | Asha | Sharma | 92.50 | 1 | 20 | 10 |
| 102 | Ravi | Kumar | 88.00 | 2 | 21 | 20 |
| 103 | Meera | Nair | 85.50 | 3 | 19 | 10 |
| 104 | Arjun | Patel | 70.00 | 4 | 22 | 30 |

### `departments`

| department_id | name | hod |
|---:|---|---|
| 10 | Computer Science | Dr. Rao |
| 20 | Physics | Dr. Sen |
| 30 | Mathematics | Dr. Iyer |
| 40 | Chemistry | Dr. Khan |

## `INNER JOIN`

An `INNER JOIN` returns only rows that have matching values in both tables.

```sql
SELECT
    students.student_id,
    students.first_name,
    departments.name AS department_name
FROM students
INNER JOIN departments
    ON students.department_id = departments.department_id;
```

The result contains each student and the name of their department. A student without a matching department and a department without students will not appear.

The keyword `INNER` is optional:

```sql
SELECT
    s.first_name,
    d.name AS department_name
FROM students AS s
JOIN departments AS d
    ON s.department_id = d.department_id;
```

Aliases such as `s` and `d` make queries shorter and easier to read.

### Inner Join with a Condition

You can filter rows after joining:

```sql
SELECT
    s.first_name,
    s.marks,
    d.name AS department_name
FROM students AS s
JOIN departments AS d
    ON s.department_id = d.department_id
WHERE s.marks >= 85
ORDER BY s.marks DESC;
```

### Inner Join with Aggregation

To count students in each department:

```sql
SELECT
    d.name AS department_name,
    COUNT(s.student_id) AS student_count,
    ROUND(AVG(s.marks), 2) AS average_marks
FROM departments AS d
JOIN students AS s
    ON d.department_id = s.department_id
GROUP BY d.department_id, d.name
ORDER BY average_marks DESC;
```

Only departments with at least one student appear because this is an inner join.

### Inner Join with Student Details

Select student details together with the department name:

```sql
SELECT
    s.student_id,
    s.first_name,
    s.last_name,
    s.age,
    d.name AS department_name
FROM students AS s
INNER JOIN departments AS d
    ON s.department_id = d.department_id;
```

### Inner Join with Marks and Rank

Select high-performing students and their departments:

```sql
SELECT
    s.first_name,
    s.marks,
    s.`rank`,
    d.name AS department_name
FROM students AS s
INNER JOIN departments AS d
    ON s.department_id = d.department_id
WHERE s.marks >= 80
  AND s.`rank` <= 10
ORDER BY s.`rank`;
```

### Inner Join with an Age Condition

Find students older than 20 and display their department heads:

```sql
SELECT
    s.first_name,
    s.age,
    d.name AS department_name,
    d.hod
FROM students AS s
INNER JOIN departments AS d
    ON s.department_id = d.department_id
WHERE s.age > 20;
```

### Inner Join for a Specific Department

Find all students who belong to the Computer Science department:

```sql
SELECT
    s.student_id,
    s.first_name,
    s.last_name,
    s.marks
FROM students AS s
INNER JOIN departments AS d
    ON s.department_id = d.department_id
WHERE d.name = 'Computer Science';
```

### Inner Join with `BETWEEN`

Find students whose marks are between 70 and 90:

```sql
SELECT
    s.first_name,
    s.marks,
    d.name AS department_name
FROM students AS s
INNER JOIN departments AS d
    ON s.department_id = d.department_id
WHERE s.marks BETWEEN 70 AND 90
ORDER BY s.marks DESC;
```

### Inner Join with Multiple Departments

Find students from selected departments:

```sql
SELECT
    s.first_name,
    d.name AS department_name
FROM students AS s
INNER JOIN departments AS d
    ON s.department_id = d.department_id
WHERE d.name IN ('Computer Science', 'Physics');
```

### Inner Join with a Department Name Pattern

Find students whose department name contains the word `Science`:

```sql
SELECT
    s.first_name,
    d.name AS department_name
FROM students AS s
INNER JOIN departments AS d
    ON s.department_id = d.department_id
WHERE d.name LIKE '%Science%';
```

### Inner Join with `LIMIT`

Find the five highest-scoring students along with their departments:

```sql
SELECT
    s.first_name,
    s.marks,
    d.name AS department_name
FROM students AS s
INNER JOIN departments AS d
    ON s.department_id = d.department_id
ORDER BY s.marks DESC
LIMIT 5;
```

### Inner Join with `COUNT`

Count how many students belong to each department:

```sql
SELECT
    d.name AS department_name,
    COUNT(s.student_id) AS student_count
FROM departments AS d
INNER JOIN students AS s
    ON d.department_id = s.department_id
GROUP BY d.department_id, d.name;
```

### Inner Join with `HAVING`

Display only departments with at least two students:

```sql
SELECT
    d.name AS department_name,
    COUNT(s.student_id) AS student_count
FROM departments AS d
INNER JOIN students AS s
    ON d.department_id = s.department_id
GROUP BY d.department_id, d.name
HAVING COUNT(s.student_id) >= 2;
```

### Inner Join with a Derived Calculation

Calculate how many marks are needed to reach 100:

```sql
SELECT
    s.first_name,
    s.marks,
    100 - s.marks AS marks_needed,
    d.name AS department_name
FROM students AS s
INNER JOIN departments AS d
    ON s.department_id = d.department_id
ORDER BY marks_needed DESC;
```

## Joining More Than Two Tables

Joins can be chained to combine several related tables. For example, if a `courses` table contains `department_id`:

```text
courses(course_id, course_name, department_id)
```

You can display students, their departments, and their courses:

```sql
SELECT
    s.first_name,
    d.name AS department_name,
    c.course_name
FROM students AS s
JOIN departments AS d
    ON s.department_id = d.department_id
JOIN courses AS c
    ON d.department_id = c.department_id;
```

## Joining with Multiple Conditions

More than one condition can be used in the `ON` clause:

```sql
SELECT
    s.first_name,
    d.name AS department_name
FROM students AS s
JOIN departments AS d
    ON s.department_id = d.department_id
   AND d.name <> 'Physics';
```

The `ON` clause describes how rows are related. The `WHERE` clause filters the joined result.

## Self Joins with a `buddies` Table

A **self join** is a join in which a table is joined with itself. It is useful when rows in the same table are related to one another.

Suppose the `buddies` table has these columns:

```text
buddies(student_id, name, email, buddy_id, age)
```

Both columns refer to students, but they have different roles:

- `student_id` is the ID of the student.
- `name`, `email`, and `age` store the student's details.
- `buddy_id` is that student's buddy.

Example data:

| student_id | name | email | buddy_id | age |
|---:|---|---|---:|---:|
| 101 | Asha | asha@example.com | 102 | 20 |
| 102 | Ravi | ravi@example.com | 104 | 21 |
| 103 | Meera | meera@example.com | 101 | 19 |
| 104 | Arjun | arjun@example.com | 103 | 22 |

This means:

- Student `101` has student `102` as a buddy.
- Student `102` has student `104` as a buddy.
- Student `103` has student `101` as a buddy.
- Student `104` has student `103` as a buddy.

### Finding Student and Buddy Names

The `buddies` table must be joined with itself. Use one alias for the student and another alias for the buddy:

```sql
SELECT
    student.name AS student_name,
    buddy.name AS buddy_name
FROM buddies AS student
INNER JOIN buddies AS buddy
    ON student.buddy_id = buddy.student_id;
```

The `buddies` table is used twice with two different aliases:

- `student` represents the student.
- `buddy` represents the student's buddy.

The aliases are necessary because both sides of the relationship come from the same table.

### Displaying Student and Buddy Details

You can select details from both copies of the table:

```sql
SELECT
    student.student_id,
    student.name AS student_name,
    student.email AS student_email,
    student.age AS student_age,
    buddy.student_id AS buddy_id,
    buddy.name AS buddy_name,
    buddy.email AS buddy_email,
    buddy.age AS buddy_age
FROM buddies AS student
INNER JOIN buddies AS buddy
    ON student.buddy_id = buddy.student_id;
```

### Finding Buddies Older Than Their Students

The self join can be combined with a `WHERE` condition:

```sql
SELECT
    student.name AS student_name,
    buddy.name AS buddy_name,
    student.age AS student_age,
    buddy.age AS buddy_age
FROM buddies AS student
INNER JOIN buddies AS buddy
    ON student.buddy_id = buddy.student_id
WHERE buddy.age > student.age;
```

This returns only relationships where the buddy is older than the student.

### Finding Mutual Buddy Relationships

To find pairs where two students are buddies with each other, join the table twice in both directions:

```sql
SELECT
    student.name AS student_name,
    buddy.name AS buddy_name
FROM buddies AS student
INNER JOIN buddies AS buddy
    ON student.buddy_id = buddy.student_id
   AND buddy.buddy_id = student.student_id;
```

The second condition checks that the relationship exists in reverse as well.
