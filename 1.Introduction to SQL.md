## 1. What Is Data?

**Data** is a collection of raw facts, values, observations, or symbols. Data may be numbers, text, dates, images, audio, or any other values that can be stored and processed.

### Examples of Data

- Student name: `Ravi Kumar`
- Age: `20`
- Product price: `499.00`
- Date of birth: `2005-04-12`
- Customer email: `customer@example.com`

Raw data may not be useful until it is organized and interpreted.

### Data and Information

**Information** is data that has been processed and given meaning.

```text
Data:        75, 82, 91
Information: The student's average mark is 82.67.
```

A database stores data, while queries and reports can turn that data into useful information.

### Common Types of Data

- **Structured data:** Organized in a fixed format, such as rows and columns.
- **Semi-structured data:** Has some organization but does not follow a strict table structure, such as JSON or XML.
- **Unstructured data:** Does not have a fixed structure, such as photographs, videos, and audio files.

---

## 2. What Is a Database?

A **database** is an organized collection of related data that can be stored, searched, updated, and managed efficiently.

For example, a school database may store:

- Student details
- Course details
- Teacher details
- Attendance
- Examination results
- Fee payments

A database is not simply a folder full of files. It has an organized structure and rules that help users access accurate data.

### Characteristics of a Database

- Stores related data in an organized way
- Allows data to be searched and retrieved
- Supports inserting, modifying, and deleting data
- Can be shared by multiple users
- Helps maintain data security and consistency
- Can preserve relationships between different types of data

---

## 3. What Is DBMS?

A **Database Management System (DBMS)** is software used to create, store, organize, retrieve, update, and control data in a database.

The DBMS provides communication between users or application programs and the database.

```text
User or Application
        |
        v
      DBMS
        |
        v
    Database
```

### Examples of DBMS Software

- MySQL
- PostgreSQL
- Oracle Database
- Microsoft SQL Server
- SQLite
- MongoDB

### Main Functions of a DBMS

1. **Data definition:** Creates databases, tables, and other database objects.
2. **Data manipulation:** Inserts, updates, deletes, and retrieves data.
3. **Security:** Controls which users can access or modify data.
4. **Integrity:** Prevents invalid or inconsistent data.
5. **Concurrency control:** Coordinates multiple users working at the same time.
6. **Backup and recovery:** Helps restore data after errors or failures.
7. **Transaction management:** Ensures that related operations are completed reliably.
8. **Query processing:** Executes user queries and returns results.

---

## 4. What Is RDBMS?

A **Relational Database Management System (RDBMS)** is a type of DBMS that stores data in tables and represents relationships between tables.

The relational model was based on the idea that data can be represented using relations, which are commonly displayed as tables.

### Main Features of an RDBMS

- Stores data in tables
- Uses rows and columns
- Uses keys to identify and connect records
- Supports SQL queries
- Enforces constraints and data integrity
- Usually supports transactions and ACID properties
- Can reduce duplication through normalization

### Example

A school system might use these related tables:

- `students`
- `courses`
- `enrollments`
- `examinations`

The `enrollments` table can connect students to courses using student and course IDs.

### Examples of RDBMS Software

- MySQL
- PostgreSQL
- Oracle Database
- Microsoft SQL Server
- MariaDB
- SQLite

---

## 5. DBMS vs RDBMS

An RDBMS is a specialized type of DBMS. Therefore, every RDBMS is a DBMS, but not every DBMS is an RDBMS.

| Feature | DBMS | RDBMS |
|---|---|---|
| Meaning | General software for managing databases | DBMS based on the relational model |
| Data organization | May use files, records, objects, or tables | Uses related tables |
| Relationships | May or may not support formal relationships | Uses keys and relationships |
| Data redundancy | Reduction depends on the system and design | Usually reduced using normalization |
| Constraints | Support varies | Commonly supports keys and integrity constraints |
| Transactions | Support varies | Usually provides strong transaction support |
| Query language | Depends on the product | Commonly uses SQL |
| Examples | Hierarchical, network, object-oriented, and relational systems | MySQL, PostgreSQL, Oracle, SQL Server |

### Simple Explanation

- **DBMS:** A broad category of database management software.
- **RDBMS:** A DBMS that stores data in related tables.

## 6. What Is MySQL?

**MySQL** is an open-source relational database management system. It uses SQL to create, read, update, and delete data.

MySQL is widely used in:

- Websites and web applications
- E-commerce systems
- Content management systems
- Banking and business applications
- Student and library management systems
- Backend services and APIs

### Important MySQL Features

- Open-source Community Edition
- Works on Windows, macOS, and Linux
- Supports SQL and relational tables
- Supports indexes, constraints, and transactions
- Provides user accounts and privileges
- Supports client tools such as MySQL Workbench
- Can be used with programming languages such as Java, Python, PHP, and JavaScript

### MySQL Architecture in Simple Terms

A MySQL installation commonly includes:

1. **MySQL Server:** Stores databases and processes SQL statements.
2. **MySQL Client:** Sends commands to the server and displays results.
3. **MySQL Workbench:** A graphical tool for working with the server.
4. **Connector or driver:** Allows an application to communicate with MySQL.

## 7. MySQL vs SQL

**SQL** and **MySQL** are not the same thing.

- **SQL (Structured Query Language)** is a standard language used to communicate with relational databases.
- **MySQL** is a database management system that understands and executes SQL commands.

### Analogy

SQL is like a language used to give instructions. MySQL is one of the systems that understands and carries out those instructions.

### Comparison

| SQL | MySQL |
|---|---|
| A query language | A relational database management system |
| Defines commands and syntax | Stores data and executes commands |
| Can be used with many relational systems | Is one specific database product |
| Includes commands such as `SELECT`, `INSERT`, and `UPDATE` | Implements SQL and adds product-specific features |
| Does not store data by itself | Stores and manages databases |

### Basic SQL Example

```sql
SELECT *
FROM students;
```

This is an SQL statement. When sent to a MySQL server, MySQL processes it and returns rows from the `students` table.

### SQL Command Categories

- **DDL (Data Definition Language):** Defines database structures. Examples: `CREATE`, `ALTER`, `DROP`.
- **DML (Data Manipulation Language):** Changes stored data. Examples: `INSERT`, `UPDATE`, `DELETE`.
- **DQL (Data Query Language):** Retrieves data. Main command: `SELECT`.
- **DCL (Data Control Language):** Controls access. Examples: `GRANT`, `REVOKE`.
- **TCL (Transaction Control Language):** Controls transactions. Examples: `COMMIT`, `ROLLBACK`.

## 8. Relational Database

A **relational database** stores data in tables and connects related tables using common columns and keys.

### Example

A `students` table can store student information:

| student_id | student_name | department |
|---:|---|---|
| 1 | Asha | Computer Science |
| 2 | Ravi | Physics |

A separate `courses` table can store course information:

| course_id | course_name |
|---:|---|
| 101 | Database Systems |
| 102 | Operating Systems |

An `enrollments` table can connect students and courses:

| student_id | course_id |
|---:|---:|
| 1 | 101 |
| 1 | 102 |
| 2 | 101 |

This design avoids placing every course detail repeatedly in the student table.

### Benefits of Relational Databases

- Data is organized in a clear table format.
- Relationships can be represented using keys.
- SQL provides powerful querying.
- Constraints help maintain valid data.
- Tables can be joined to produce combined results.
- The structure is suitable for many business applications.

### Common Relational Database Terms

- **Relation:** A table.
- **Tuple:** A row in a table.
- **Attribute:** A column in a table.
- **Domain:** The allowed set of values for an attribute.
- **Primary key:** A column or group of columns that uniquely identifies a row.
- **Foreign key:** A column that refers to a key in another table.

## 9. Tables, Rows, and Columns

### Table

A **table** is a collection of related data organized into rows and columns.

Example table: `students`

| student_id | student_name | age | department |
|---:|---|---:|---|
| 1 | Asha | 20 | Computer Science |
| 2 | Ravi | 21 | Physics |

### Row

A **row** is one complete entry in a table. It describes one item or entity.

In the example above, this is one row:

```text
1 | Asha | 20 | Computer Science
```

That row contains all stored details for one student.

### Column

A **column** represents one property or characteristic of the items in a table.

Examples:

- `student_id`
- `student_name`
- `age`
- `department`

Each column usually has a data type, such as `INT`, `VARCHAR`, `DATE`, or `DECIMAL`.

### Field

A **field** is a single value in a particular row and column. For example, `Asha` is a field value in the `student_name` column.

---

## 10. Database, Table, and Record

These terms describe different levels of organization.

```text
Database
└── Table
    └── Record (row)
        └── Field value
```

### Database

A **database** is a container that can hold multiple related tables and other objects.

Example: `college_db`

### Table

A **table** stores a particular type of entity or relationship.

Examples:

- `students`
- `teachers`
- `courses`
- `enrollments`

### Record

A **record** is one row in a table. It contains information about one entity or one relationship.

Example record in `students`:

```text
student_id: 1
student_name: Asha
age: 20
department: Computer Science
```

### Field

A **field** is an individual piece of information in a record.

In the record above, `Asha` is the value of the `student_name` field.

### Important Distinction

- A **database** can contain many tables.
- A **table** contains many records.
- A **record** contains values for many fields.
- A **column** defines the type of value stored in a position.

## 11. Installing MySQL

MySQL usually requires the MySQL Server and, optionally, a client tool such as MySQL Workbench.

### Components to Install

- **MySQL Server:** The main service that stores and manages databases.
- **MySQL Workbench:** A graphical interface for SQL development and database administration.
- **MySQL Shell or command-line client:** A text-based interface for running SQL commands.
- **MySQL Connector:** A driver used by applications to connect to MySQL.

### General Installation Steps

The exact screens may vary by operating system and installer version.

1. Download MySQL from the official MySQL website.
2. Choose the installer appropriate for your operating system.
3. Select MySQL Server and, if needed, MySQL Workbench.
4. Choose the installation type.
5. Configure MySQL as a server.
6. Select the default or appropriate configuration settings.
7. Choose an authentication method.
8. Set a strong password for the administrative account.
9. Configure MySQL to run as a service if the installer offers that option.
10. Complete the installation.
11. Open MySQL Workbench or the command-line client.
12. Test the connection to the server.

### Important Installation Notes

- Remember the administrative password securely.
- Avoid sharing database passwords.
- Use a separate user for applications instead of using the administrator account.
- Keep the server and tools updated.
- Do not expose a database server to the public internet without proper security configuration.

### Checking a MySQL Connection

After connecting to MySQL, run:

```sql
SELECT VERSION();
```

This displays the version of the MySQL server.

You can also run:

```sql
SELECT CURRENT_USER();
```

This displays the account being used for the current connection.

### Common Installation Problems

- **Server is not running:** Start the MySQL service and try again.
- **Wrong password:** Verify the username and password entered during setup.
- **Port conflict:** Another service may already be using the default MySQL port, commonly `3306`.
- **Connection refused:** Check that the server is running and the host and port are correct.
- **Permission error:** Use an account with suitable privileges or ask the database administrator.

## 12. MySQL Workbench

**MySQL Workbench** is a graphical application used to work with MySQL databases.

### Common Uses

- Connect to a MySQL server
- Write and execute SQL queries
- Create and modify database objects
- View query results
- Design database diagrams
- Import and export data
- Manage users and privileges
- Monitor server activity

### Main Workbench Areas

- **Home screen:** Shows saved database connections.
- **SQL Editor:** Used to write and execute SQL statements.
- **Navigator panel:** Displays schemas, tables, views, procedures, and other objects.
- **Output or result panel:** Displays query results, messages, warnings, and errors.
- **Modeling tools:** Help create entity-relationship diagrams and database designs.

### Connecting to MySQL Workbench

1. Open MySQL Workbench.
2. Select an existing connection or create a new one.
3. Enter the hostname, port, username, and password.
4. Open the connection.
5. Create a new SQL tab.
6. Run a simple test query:

```sql
SELECT 'Connection successful' AS message;
```

### Running a Query

1. Type the SQL statement in the SQL Editor.
2. Place the cursor inside the statement or select the statement.
3. Click the execute button.
4. Read the results in the output area.
5. Check the error message if the query fails.

### Good Workbench Practices

- Read the selected database shown in the SQL Editor before running a query.
- Use semicolons to end SQL statements.
- Save important scripts in `.sql` files.
- Review `UPDATE` and `DELETE` statements carefully before executing them.
- Use comments to label sections of a learning script.

SQL comments can be written as:

```sql
-- This is a single-line comment

/* This is a
   multi-line comment */
```

## 13. Creating a Database

The SQL command used to create a database is `CREATE DATABASE`.

### Syntax

```sql
CREATE DATABASE database_name;
```

### Example

```sql
CREATE DATABASE college_db;
```

This creates a database named `college_db`.

### Avoiding an Error if the Database Already Exists

```sql
CREATE DATABASE IF NOT EXISTS college_db;
```

`IF NOT EXISTS` tells MySQL to create the database only when it is not already present.

### Creating a Database with Character Set and Collation

Character sets define how text is stored. Collations define how text is compared and sorted.

```sql
CREATE DATABASE college_db
    CHARACTER SET utf8mb4
    COLLATE utf8mb4_unicode_ci;
```

`utf8mb4` is commonly used because it supports a wide range of Unicode characters.

### Important Note

Creating a database does not automatically create tables. Tables must be created separately inside the database.

## 14. Selecting a Database

Before creating or using tables, select the database with the `USE` command.

### Syntax

```sql
USE database_name;
```

### Example

```sql
USE college_db;
```

After this command, subsequent table-related commands apply to `college_db`, unless another database is explicitly named.

### Checking the Selected Database

```sql
SELECT DATABASE();
```

If a database is selected, MySQL returns its name. If no database is selected, the result is `NULL`.

### Why Selecting a Database Matters

Suppose two databases both contain a table named `students`. If you do not select the correct database, you may create or query the table in the wrong location.

You can also specify a database directly:

```sql
SELECT *
FROM college_db.students;
```

The format is:

```text
database_name.table_name
```

## 15. Showing Databases

The `SHOW DATABASES` command lists the databases that the current MySQL user is allowed to see.

### Syntax

```sql
SHOW DATABASES;
```

### Example Output

The output may include system databases and user-created databases:

```text
information_schema
mysql
performance_schema
sys
college_db
```

### Important Notes

- The output depends on the user's privileges.
- You may not see every database on the server.
- System databases are used by MySQL internally.
- `SHOW DATABASES;` does not display the tables inside a database.

### Finding a Database with a Pattern

MySQL also allows a pattern:

```sql
SHOW DATABASES LIKE 'college%';
```

This displays databases whose names begin with `college`.

---

## 16. Showing Tables

After selecting a database, use `SHOW TABLES` to list its tables.

### Steps

```sql
USE college_db;
SHOW TABLES;
```

### Example Output

```text
courses
students
```

### Showing Tables Without Selecting the Database

You can qualify the database name:

```sql
SHOW TABLES FROM college_db;
```

### Important Notes

- `SHOW TABLES;` lists tables in the currently selected database.
- If no database is selected, MySQL may return an error asking you to select one.
- A newly created database has no user tables until you create them.

### Example: Create a Table and Show It

```sql
USE college_db;

CREATE TABLE students (
    student_id INT PRIMARY KEY,
    student_name VARCHAR(100) NOT NULL,
    department VARCHAR(100),
    age INT
);

SHOW TABLES;
```

The result should include `students`.

## 17. Describing a Table

To view the structure of a table, use `DESCRIBE` or its shorter form, `DESC`.

### Syntax

```sql
DESCRIBE table_name;
```

or:

```sql
DESC table_name;
```

### Example

```sql
DESCRIBE students;
```

### Typical Output

| Field | Type | Null | Key | Default | Extra |
|---|---|---|---|---|---|
| student_id | int | NO | PRI | NULL | |
| student_name | varchar(100) | NO | | NULL | |
| department | varchar(100) | YES | | NULL | |
| age | int | YES | | NULL | |

### Meaning of the Output Columns

- **Field:** Name of the column.
- **Type:** Data type and size of the column.
- **Null:** Whether the column can contain `NULL`.
- **Key:** Key information, such as `PRI` for primary key.
- **Default:** Value used when no value is provided, if one is defined.
- **Extra:** Additional information, such as auto-increment behavior.

### Showing the Complete Table Definition

Use `SHOW CREATE TABLE` to view the SQL statement used to define a table:

```sql
SHOW CREATE TABLE students;
```

This is useful for checking column definitions, constraints, indexes, storage options, and character settings.

## Complete Practice Script

The following script demonstrates the main commands from this module.

```sql
-- Create a database
CREATE DATABASE IF NOT EXISTS college_db;

-- Select the database
USE college_db;

-- Display the selected database
SELECT DATABASE();

-- Create a table
CREATE TABLE IF NOT EXISTS students (
    student_id INT PRIMARY KEY,
    student_name VARCHAR(100) NOT NULL,
    email VARCHAR(150) UNIQUE,
    department VARCHAR(100),
    age INT
);

-- List tables in the selected database
SHOW TABLES;

-- View the table structure
DESCRIBE students;

-- View the complete table definition
SHOW CREATE TABLE students;
```

### Expected Learning Result

After running the script:

1. The `college_db` database exists.
2. `college_db` is selected for the current session.
3. The `students` table exists inside it.
4. `SHOW TABLES;` displays `students`.
5. `DESCRIBE students;` displays the table columns and constraints.

## Important SQL Syntax Rules

- SQL keywords are commonly written in uppercase for readability, although MySQL usually accepts lowercase keywords.
- End statements with a semicolon: `;`
- Database, table, and column names should be chosen clearly.
- Avoid spaces in object names; use names such as `student_records` instead of `student records`.
- Use single quotes for text values, such as `'Asha'`.
- Use backticks only when an identifier needs quoting, such as a reserved word or a name containing special characters.
- SQL keywords are generally not case-sensitive, but database and table name behavior can depend on the operating system and MySQL configuration.
- Use comments to make scripts easier to understand.

## Common Beginner Errors

### Error: No Database Selected

**Cause:** A table command was executed before selecting a database.

**Solution:** Run:

```sql
USE college_db;
```

### Error: Database Already Exists

**Cause:** The database name has already been created.

**Solution:** Use:

```sql
CREATE DATABASE IF NOT EXISTS college_db;
```

### Error: Table Already Exists

**Cause:** A table with the same name is already in the selected database.

**Solution:** Use:

```sql
CREATE TABLE IF NOT EXISTS students (...);
```

Only use `DROP TABLE` when you are certain that the existing table and its data are no longer needed.

### Error: Access Denied

**Cause:** The current user does not have the required privilege or the password is incorrect.

**Solution:** Check the login details or contact the database administrator.

### Error: Unknown Database

**Cause:** The database name is misspelled or has not been created.

**Solution:** Run:

```sql
SHOW DATABASES;
```

Then select the correct name.
