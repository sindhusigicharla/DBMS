# SQL Subqueries — Notes

## 1. What is a Subquery?

A **subquery** is a SQL query written inside another SQL query. It is also called a nested query or inner query.

- **Inner query:** The query inside another query.
- **Outer query:** The main query that uses the subquery result.

### Syntax

```sql
SELECT column_name
FROM table_name
WHERE column_name = (
    SELECT column_name
    FROM another_table
);
```

## 3. Types of Subqueries

### A. Single-Row Subquery

Returns a single row or value.

**Example: Find employees earning more than the average salary.**

```sql
SELECT employee_name, salary
FROM employees
WHERE salary > (
    SELECT AVG(salary)
    FROM employees
);
```

### B. Multiple-Row Subquery

Returns multiple rows. Operators such as `IN`, `ANY`, and `ALL` can be used.

**Example: Find employees working in departments 1 or 2.**

```sql
SELECT employee_name
FROM employees
WHERE department_id IN (
    SELECT department_id
    FROM departments
);
```

### C. Correlated Subquery

A correlated subquery refers to a column from the outer query.

**Example: Find employees earning more than their department's average salary.**

```sql
SELECT employee_name, salary
FROM employees e
WHERE salary > (
    SELECT AVG(salary)
    FROM employees
    WHERE department_id = e.department_id
);
```

## 4. Important Operators

| Operator | Purpose |
|---|---|
| `=` | Matches a single value |
| `IN` | Matches any value in a list |
| `NOT IN` | Excludes matching values |
| `ANY` | Condition must match at least one value |
| `ALL` | Condition must match every value |
| `EXISTS` | Checks whether rows exist |
| `NOT EXISTS` | Checks whether matching rows do not exist |

## 5. Subquery Using `MAX()`

**Question:** Find the employee receiving the highest salary.

```sql
SELECT employee_name, salary
FROM employees
WHERE salary = (
    SELECT MAX(salary)
    FROM employees
);
```

## 6. Subquery Using `MIN()`

**Question:** Find the employee receiving the lowest salary.

```sql
SELECT employee_name, salary
FROM employees
WHERE salary = (
    SELECT MIN(salary)
    FROM employees
);
```

## 7. Subquery Using `IN`

**Question:** Find employees working in departments that exist in the departments table.

```sql
SELECT employee_name
FROM employees
WHERE department_id IN (
    SELECT department_id
    FROM departments
);
```

## 8. Subquery Using `EXISTS`

**Question:** Find departments that have employees.

```sql
SELECT department_name
FROM departments d
WHERE EXISTS (
    SELECT 1
    FROM employees e
    WHERE e.department_id = d.department_id
);
```

## 9. Subquery vs JOIN

| Subquery | JOIN |
|---|---|
| Uses one query inside another | Combines rows from multiple tables |
| Useful for comparisons and filtering | Useful for retrieving related data |
| Can use aggregate results such as `AVG()` and `MAX()` | Can display columns from related tables |

## 10. Important Points

1. A subquery must be enclosed in parentheses.
2. A subquery can be used with `SELECT`, `INSERT`, `UPDATE`, and `DELETE`.
3. Use `IN` when a subquery returns multiple values.
4. Use `EXISTS` to check whether matching rows exist.
5. A scalar subquery must return at most one row.
6. Use aliases for derived tables in the `FROM` clause.
7. Be careful with `NOT IN` if the subquery can return `NULL`.
