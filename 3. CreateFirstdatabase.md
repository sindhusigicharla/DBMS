# Creating Your First Database

In this section, we will create our first database, called `college`, and add a `students` table to it.

## Creating the `college` Database

Use the `CREATE DATABASE` statement:

```sql
CREATE DATABASE college;
```

If the database already exists, the statement will return an error. To avoid that error, use `IF NOT EXISTS`:

```sql
CREATE DATABASE IF NOT EXISTS college;
```

## Selecting the Database

Before creating tables, select the database with the `USE` statement:

```sql
USE college;
```

All tables created after this command will be created inside the `college` database.

## Creating the `students` Table

The `students` table will contain the following columns:

- `student_id`: A unique identifier for each student
- `first_name`: The student's first name
- `last_name`: The student's last name
- `email`: The student's email address
- `phone`: The student's phone number
- `marks`: The student's marks
- `rank`: The student's rank

```sql
CREATE TABLE students (
    student_id INT PRIMARY KEY,
    first_name VARCHAR(50) NOT NULL,
    last_name VARCHAR(50) NOT NULL,
    email VARCHAR(255) UNIQUE NOT NULL,
    phone VARCHAR(20),
    marks DECIMAL(5, 2),
    `rank` INT
);
```

### Why These Data Types?

- `INT` is suitable for whole numbers such as IDs and ranks.
- `VARCHAR` is suitable for names, email addresses, and phone numbers.
- A phone number is stored as text because it may contain a country code, spaces, or leading zeroes.
- `DECIMAL(5, 2)` can store marks such as `95.50` accurately.
- Backticks around `` `rank` `` allow the column name to be used safely because `RANK` is a ranking-related SQL keyword in some database systems.

## Complete Script

The complete script is:

```sql
CREATE DATABASE IF NOT EXISTS college;

USE college;

CREATE TABLE students (
    student_id INT PRIMARY KEY,
    first_name VARCHAR(50) NOT NULL,
    last_name VARCHAR(50) NOT NULL,
    email VARCHAR(255) UNIQUE NOT NULL,
    phone VARCHAR(20),
    marks DECIMAL(5, 2),
    `rank` INT
);
```

## Checking the Table

To confirm that the table was created, display the tables in the selected database:

```sql
SHOW TABLES;
```

To view the columns and their data types:

```sql
DESCRIBE students;
```

## Inserting Rows into a Table

Use the `INSERT INTO` statement to add rows to the `students` table.

### Inserting One Row

Specify the column names and provide a value for each column:

```sql
INSERT INTO students (
    student_id,
    first_name,
    last_name,
    email,
    phone,
    marks,
    `rank`
)
VALUES (
    101,
    'Asha',
    'Sharma',
    'asha@example.com',
    '9876543210',
    92.50,
    1
);
```

Text values must be enclosed in single quotes. Numeric values do not require quotes.

### Inserting Multiple Rows

Multiple rows can be inserted using one statement:

```sql
INSERT INTO students (
    student_id,
    first_name,
    last_name,
    email,
    phone,
    marks,
    `rank`
)
VALUES
    (102, 'Ravi', 'Kumar', 'ravi@example.com', '9876543211', 88.00, 2),
    (103, 'Meera', 'Nair', 'meera@example.com', '9876543212', 85.50, 3);
```

### Inserting Values for Selected Columns

You do not have to provide values for every column. Columns that are omitted receive `NULL` or their defined default value, provided they are not required by a `NOT NULL` constraint.

```sql
INSERT INTO students (
    student_id,
    first_name,
    last_name,
    email
)
VALUES (
    104,
    'Arjun',
    'Patel',
    'arjun@example.com'
);
```

In this example, `phone`, `marks`, and `rank` are omitted, so their values are `NULL`.

### Checking Inserted Rows

Use `SELECT` to verify the inserted data:

```sql
SELECT *
FROM students;
```

It is good practice to specify column names in an `INSERT` statement rather than relying on the table's column order. This makes the query clearer and safer if the table structure changes.

## Updating Rows

Use the `UPDATE` statement to modify existing data in a table.

### Updating One Row

The `WHERE` clause identifies the row to update:

```sql
UPDATE students
SET marks = 95.00,
    `rank` = 1
WHERE student_id = 101;
```

This updates only the student whose `student_id` is `101`.

### Updating Multiple Columns

You can update more than one column in the same statement by separating assignments with commas:

```sql
UPDATE students
SET phone = '9876500000',
    email = 'asha.sharma@example.com'
WHERE student_id = 101;
```

### Updating Multiple Rows

If the condition matches multiple rows, all matching rows are updated:

```sql
UPDATE students
SET marks = marks + 5
WHERE marks < 40;
```

### Important Warning

Always check the `WHERE` clause before running an `UPDATE`. If `WHERE` is omitted, every row in the table will be updated:

```sql
UPDATE students
SET marks = 0;
```

The statement above sets the marks of every student to `0`.

## Deleting Rows

Use the `DELETE` statement to remove rows from a table.

### Deleting One Row

Use a primary key or another unique column to target one specific row:

```sql
DELETE FROM students
WHERE student_id = 104;
```

### Deleting Multiple Rows

If the condition matches multiple rows, all matching rows are deleted:

```sql
DELETE FROM students
WHERE marks < 40;
```

### Important Warning

Always verify the `WHERE` clause before running a `DELETE`. If `WHERE` is omitted, every row in the table will be deleted:

```sql
DELETE FROM students;
```

This removes all rows but keeps the `students` table and its structure. To remove the table itself, use `DROP TABLE`.

### Checking the Result

Use `SELECT` before or after an update or delete to check the affected data:

```sql
SELECT *
FROM students
WHERE student_id = 101;
```

## TRUNCATE

`TRUNCATE` removes all rows from a table but keeps the table itself. The table structure, columns, and constraints remain available for inserting new data.

```sql
TRUNCATE TABLE students;
```

After this command, the `students` table still exists, but it contains no records. Use `TRUNCATE` when you want to empty a table completely and reuse its structure.

## DROP

`DROP` permanently removes a database object, such as a table or a database.

To remove only the `students` table:

```sql
DROP TABLE students;
```

To remove the complete `college` database, including all its tables and data:

```sql
DROP DATABASE college;
```

After a `DROP` operation, the removed object no longer exists. Recreating it requires another `CREATE TABLE` or `CREATE DATABASE` statement.

## TRUNCATE vs DROP

| Feature | `TRUNCATE` | `DROP` |
|---|---|---|
| Main purpose | Removes all rows from a table | Removes the table or database itself |
| Table structure | Preserved | Deleted |
| Data | Deleted | Deleted |
| Can the table be reused immediately? | Yes | No, it must be recreated |
| Example | `TRUNCATE TABLE students;` | `DROP TABLE students;` |

Both commands can permanently remove data, so verify the target before executing them. Use `TRUNCATE` to empty a table and `DROP` to remove the table or database completely.
